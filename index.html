Datenschutzerklärung

Verantwortlicher: Klassensprecher, Christopher Schule Reim.

Welche Daten werden erhoben? Wenn du das Kontaktformular nutzt, werden dein eingegebener Name (falls angegeben), deine Nachricht und der Sendezeitpunkt gespeichert. Beim Klick auf "Ich wähle dich!" wird nur gezählt, dass eine Stimme abgegeben wurde — nicht wer du bist.

Wofür werden die Daten genutzt? Ausschließlich, damit ich als Kandidat/in Nachrichten lesen und beantworten kann. Es findet keine Weitergabe an Dritte statt.

Wie lange werden Daten gespeichert? Bis ich Nachrichten manuell lösche.

Deine Rechte: Du kannst jederzeit eine gesendete Nachricht per Ansprache im Schulhof zurückziehen oder deren Löschung verlangen.
